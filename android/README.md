# BookCreator Android

Natywna aplikacja Android jest opakowaniem produkcyjnego BookCreatora: https://bookcreator-prototyp.vercel.app

Projekt używa Android WebView, dzięki czemu BookCreator uruchamia się jako osobna aplikacja bez paska Chrome.

Do zbudowania APK otwórz katalog `android` w Android Studio i zbuduj aplikację.
